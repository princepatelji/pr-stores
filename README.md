# PR Stores

A simple static Amazon Associate product showcase with:
- Product search and sorting
- Product cards with images/specifications
- Add to Cart
- Buy on Amazon links
- Local admin panel for adding/deleting products
- Mobile responsive design

## Run
Open `index.html` in a browser.

## Admin
Demo password: `prstores123`

IMPORTANT:
This starter admin uses browser localStorage and is NOT secure for a production store. Do not use it to protect real secrets. For a real production admin system, use server-side authentication and a database.

## Amazon Associate compliance
Use only your own valid Amazon Associate links and follow the current Amazon Associates Program policies. Do not imply that PR Stores is Amazon.
